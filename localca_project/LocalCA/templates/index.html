The Vue frontend has not been built, so there is no application shell to serve. The API is running normally: see /api/session/.

Build the frontend

  1. Install the dependencies: 
    cd frontend
pnpm install
  2. Produce the bundle Django serves (writes frontend/dist): 
    pnpm build
  3. Reload this page.

During development you can instead run pnpm dev, which serves the app on http://localhost:5173 and proxies /api to this Django process.
